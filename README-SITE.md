# СТМ МЕБЕЛЬ — V6

Мобильный сайт для корпусной мебели на заказ в Красноярске.

## V6
- Основной домен: https://стм-мебель.рф/
- SEO: canonical, Open Graph, sitemap.xml, robots.txt
- Портфолио с полноэкранной каруселью и свайпом
- MAX вместо WhatsApp/Instagram
- 7 проектов, два проекта содержат по 2 фотографии
- WebP-изображения

## Публикация
Загрузить содержимое архива в корень GitHub-репозитория `stm-mebel-site`, затем подключить пользовательский домен в Cloudflare Pages.
