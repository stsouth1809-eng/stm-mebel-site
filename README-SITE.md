# СТМ МЕБЕЛЬ — обновление сайта

## Контакты
Меняйте номер и ссылки в `config.js`.

## Добавление проекта
1. Добавьте фото в `images/`, например `project-10.webp`.
2. Добавьте новый объект в `projects.js`.
3. Если проект должен появиться именно в текущей визуальной галерее, замените/добавьте соответствующую карточку в `index.html` — текущая галерея сохранена как статическая, чтобы не ломать дизайн.
4. Сделайте Commit в GitHub. Cloudflare опубликует новый deployment автоматически.

## MAX
Кнопка ведёт на официальный профиль `stm_mebel24`. Доступность сервиса зависит от региона и настроек сети. На сайте добавлен юридический дисклеймер.
